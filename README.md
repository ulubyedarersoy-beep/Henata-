# حِكمة (Hikma) — مشكاة الفلسفة والأرقام

تطبيق أندرويد مبني بلغة **Kotlin** و **Jetpack Compose** و **Material 3** لعرض واستكشاف **٤٠٠ اقتباس فلسفي** عبر اختيار رقم محدد أو عدد معين من الحكم والأقوال الخالدة، مع دعم كامل للغة العربية (**RTL**) والوضع الليلي والنهاري.

---

## أبرز المزايا

* **اختر رقماً (`ByNumberScreen`):** الانتقال المباشر إلى أي اقتباس من **١ إلى ٤٠٠** عبر الإدخال المباشر، شريط التمرير، أزرار السابق/التالي، الاختيار العشوائي، أو الأرقام السريعة.
* **اليوم والساعة (`DailyHourlyScreen`):** حكمة يومية ثابتة تتجدد كل يوم، وحكمة ساعية تتجدد مع مطلع كل ساعة مصحوبة بعدّاد تنازلي للتجديد.
* **اختر عدداً (`ByCountScreen`):** استعراض مجموعة مخصصة من الحكم مع إمكانية التصفية حسب المدرسة الفلسفية (الإسلامية، اليونانية، الرواقية، التنوير، الوجودية، الآسيوية) والترتيب (بالترتيب / عشوائي).
* **المفضلة (`FavoritesScreen`):** حفظ الاقتباسات المفضلة واستعراضها في أي وقت.
* **بطاقة الفيلسوف والترجمة والشرح الشخصي:**
  * عرض بطاقة تعريفية لكل فيلسوف وعدد اقتباساته في المكتبة (`PhilosopherBioCatalog`).
  * ترجمة مدمجة للإنجليزية تعمل دون اتصال بالإنترنت (`OfflineTranslationRepository`).
  * إضافة وتعديل وحذف شرح وتأمّل شخصي خاص بكل اقتباس، مع تضمينه عند النسخ أو المشاركة.

---

## التقنيات المستخدمة

* **اللغة:** Kotlin (JVM 11)
* **واجهة المستخدم:** Jetpack Compose & Material 3 (RTL + Dark/Light Theme)
* **إدارة الحالة:** MVVM مع `StateFlow` و `Kotlin Coroutines`
* **التخزين المحلي:** Jetpack DataStore (Preferences)
* **الاختبارات:** JUnit & Robolectric (`ExampleUnitTest`, `ExampleRobolectricTest`)

---

## التشغيل المحلي (Run Locally)

**المتطلبات:** [Android Studio](https://developer.android.com/studio) (JDK 11+ / Android SDK 36)

1. افتح **Android Studio** واختر **Open** ثم حدد مجلد المشروع.
2. انتظر حتى يكتمل مزامنة Gradle وتحميل الاعتماديات.
3. أنشئ ملف `.env` في المجلد الرئيسي للمشروع (يمكنك الاستعانة بملف `.env.example`) وأضف مفتاح `GEMINI_API_KEY` إذا لزم الأمر.
4. *(اختياري عند النشر)* أزل السطر `signingConfig = signingConfigs.getByName("debugConfig")` من ملف `app/build.gradle.kts` عند إعداد توقيع الإنتاج.
5. شغّل التطبيق على محاكي أندرويد (Emulator) أو جهاز حقيقي (Min SDK 24).
